## 📊 Customer Churn Analysis

### 1. The Business Challenge

In the highly competitive subscription-based market, customer retention is critical for sustainable business growth.

This project analyzes customer churn using a multi-dimensional dataset containing **customer demographics, subscription details, financial information, customer satisfaction, complaints, escalations, and churn indicators**.

The objective is to identify high-risk customer segments, understand factors associated with churn, and translate the analysis into actionable business insights.

### 2. Core Tech Stack

* **Python:** NumPy, Pandas
* **SQL / SQLite3:** Data extraction and analysis
* **Matplotlib & Seaborn:** Data visualization
* **Data Cleaning & Feature Engineering**
* **Exploratory Data Analysis (EDA)**
* **Business Insights & Recommendations**

### 3. Project Milestones

* **Relational Data Extraction:** Connected SQL database with Python using Pandas and SQLite3 and extracted customer data using SQL queries.
* **Data Cleaning:** Performed data type checks, column selection/renaming, quality checks, and handled missing/null values.
* **Feature Engineering:** Created calculated columns and performed data transformations and filtering.
* **Data Analysis:** Performed aggregation, `GROUP BY`, and pivot-table based analysis.
* **Data Visualization:** Created visualizations using Matplotlib and Seaborn.
* **Business Insights:** Identified key churn patterns and translated findings into actionable business recommendations.
